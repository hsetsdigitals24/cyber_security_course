# H-SETS — Weekly study and submission plan

This is the default proposed route: 18 teaching weeks followed by six completion weeks. Your instructor confirms dates before the cohort begins. Module IDs stay the same if the calendar changes. The intensive route requires a separate timetable for the same work; it is not the lighter route compressed without extra hours.

## Each teaching week

Plan two three-hour classes plus six independent hours. Class time includes explanation, demonstration, guided practice and feedback. Independent time includes reading, the two lesson assignments and the current project milestone. Project work already counts inside this allocation; it is not six hours plus another project allowance.

- [ ] Before class: read the prerequisite and complete the assigned refresher.
- [ ] First class: follow the first lesson and show its checkpoint.
- [ ] Between classes: complete the first lesson's assigned work and record questions.
- [ ] Second class: follow the second lesson and show its checkpoint.
- [ ] After class: finish its assignment, update the named project evidence and review feedback.
- [ ] Before the next module: confirm access to the required baseline and resolve essential prerequisite gaps.

Use the workbook's task estimates to budget your six independent hours. At the start of the week, write each activity once, estimate its duration, and add the total. If required work exceeds the allocation, show the instructor before the deadline. Reusing a lab artifact in a project needs a clear evidence link, not a second time charge. Keep actual times so the course can be adjusted after a pilot.

## Week 6: an explicit beginner budget

P01 Stage B still receives 140 minutes, now split between 60 guided and 80 independent minutes. This moves one hour into existing class time; it does not add hidden homework. The Python starter is included below. These estimates need a learner pilot.

|---|---:|

Sequence the two classes as: class A P01 Stage B 60 + Python 60 + M06 work 60; class B M06 work 100 + retrieval/feedback 35 + G1 45. Complete the 80 independent Stage B minutes between classes, before each learner's G1 slot; if a learner has not completed it, reschedule G1 rather than compressing or skipping practice. In a cohort, the instructor must roster individual assessment capacity; 45 minutes is a learner slot, not enough time to serially assess a whole class.

The P01 eight-hour project allocation is now seven independent hours plus one guided hour. Across projects, 103 of the 156 independent hours are allocated to projects and 53 to other study; the project workload is still 104 hours including that guided hour. Total course hours stay 276. Practical development reused for a project is counted once. If actual reading, setup or remediation exceeds this plan, record it and revise dated milestones before the deadline; do not claim a measured six-hour fit.
