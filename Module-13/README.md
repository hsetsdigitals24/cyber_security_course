## Your route through this module

**Before class:** M03/M09: packet capture, traffic paths, services and the P04 segmentation baseline. If you need a refresher, tell the instructor before the practical.

Use the instructor-completed [lab sheet](../H-SETS-Class-Lab-Sheet.md) to identify your machines, accounts, versions, inputs and recovery route. Bring a folder for your own evidence; do not copy demonstration results as your work.

| Stage | Open / do | Check before moving on |
|---|---|---|
| First lesson: L25 | [Read the notes](01-Student-Notes.md), discuss the worked example, then use the matching [lab section](02-Guided-Lab.md) | Correlate the client request with captured traffic and the server observation. |
| First assignment | Complete only L25 in the [workbook](03-Student-Workbook.md) | Include the named evidence and explain one result |
| Second lesson: L26 | Continue the notes and matching lab after the first checkpoint | Distinguish offline rule results from fresh live-sensor results; test match and non-match paths. |
| Second assignment | Complete L26 in the workbook | Correct feedback and record an independent variation |
| Portfolio milestone | P04: observation path and live detection evidence | Link existing evidence; do not duplicate the same activity as extra hours |

**Completion checklist:** explain both checkpoints, submit both lesson assignments, preserve required allowed/denied or comparative tests, and record recovery plus unresolved issues. Completing this module does not automatically pass its project or gate.

Plan six class hours and six independent hours in the default teaching week. The independent hours include assignment and project work. Use the [weekly planner](../H-SETS-Weekly-Study-Plan.md) for deadlines and the [assessment guide](../H-SETS-Student-Assessment-Guide.md) for marks.

**H-SETS Practical Cybersecurity Programme · L25/L26**

Prerequisites: M03 packet analysis, M09 segmentation, M10 scope. Six guided hours plus six independent hours; allocate independent time to assignments (2 h), P04 detection evidence (3 h), and correction (1 h). This is P04's detection milestone, not a ninth portfolio project. Revisit P05 reports during feedback.

Read [notes](01-Student-Notes.md), perform the [lab](02-Guided-Lab.md), and submit the [workbook](03-Student-Workbook.md). Instructor answers are separate.

Use a staged Ubuntu client and web/sensor guest or the institution's routed range. Plan 2–4 GB per guest and shut down unrelated guests on a 16 GB host. An offline capture exercise builds analysis skills but does not replace P04's live visibility and segmentation acceptance tests. Record exact installed versions before teaching.
