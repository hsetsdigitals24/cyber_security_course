## Module overview

Trace Linux connections and learn how Windows records identities, processes, services and security events.

## What you should be able to do

- Separate addressing, routing, DNS and application failures.
- Explain Linux sockets and controlled file-sharing access.
- Locate Windows process, service and event information.

## Preparation

Use the approved Linux and Windows lab systems; remote access and sharing remain inside the assigned range.

## Guided practice and independent work

Complete the assigned Linux networking and sharing exercises, then inspect the supplied Windows environment with the lesson tools. Continue Project 02 access and service work. Use evidence from both systems to explain one access or connectivity failure.

Use the [tool-lab index](../../practicals/labs/README.md) and [project index](../../practicals/projects/README.md) to open the relevant brief. A stage started this week is not the same as a completed lab or project. Record completed, deferred and not-run tasks accurately.

## Weekly checkpoint

Prepare: a network troubleshooting record and a Windows event interpretation with source and time context.

Explain the purpose of your work, the evidence supporting the result and one limitation or unresolved question. Where you tested a control, distinguish the expected result from the observed result. Use fictional or approved training data and keep credentials out of submitted evidence.
