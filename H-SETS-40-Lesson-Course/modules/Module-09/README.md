## Module overview

Keep account access aligned with responsibilities and apply protections to the devices people use.

## What you should be able to do

- Plan joiner, mover and leaver access changes.
- Distinguish antivirus, endpoint detection and disk encryption.
- Verify endpoint changes and account permissions without exposing recovery secrets.
