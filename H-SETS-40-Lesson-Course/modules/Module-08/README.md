## Module overview

Understand enterprise Windows services and administer directory objects through the graphical tools.

## What you should be able to do

- Explain DNS, DHCP, server roles and directory dependencies.
- Distinguish domains, forests, OUs, groups and resource permissions.
- Configure and verify the assigned directory and Group Policy settings through the GUI.

## Preparation

The instructor must provision the isolated Windows range and recovery route. Read-only reference commands may supplement GUI evidence.

## Guided practice and independent work

Begin Tool Lab 04 using Server Manager, DNS Manager, Active Directory Users and Computers and Group Policy Management. Use the Group Policy Results Wizard for applied-policy evidence. Keep endpoint and central-monitoring stages for their later lessons.

Use the [tool-lab index](../../practicals/labs/README.md) and [project index](../../practicals/projects/README.md) to open the relevant brief. A stage started this week is not the same as a completed lab or project. Record completed, deferred and not-run tasks accurately.

## Weekly checkpoint

Prepare: a directory diagram, GUI configuration evidence, group-based access tests and a policy-results report.

Explain the purpose of your work, the evidence supporting the result and one limitation or unresolved question. Where you tested a control, distinguish the expected result from the observed result. Use fictional or approved training data and keep credentials out of submitted evidence.
