## Questions

1. Which part of the CIA Triad protects information from unauthorized access or disclosure?
   A. Availability
   B. Confidentiality
   C. Integrity
   D. Recovery

2. A hospital cannot access its electronic health record system during patient care. Which CIA principle is most affected?
   A. Availability
   B. Confidentiality
   C. Integrity
   D. Non-repudiation

3. A bank transaction record is changed without approval. Which CIA principle is most affected?
   A. Availability
   B. Confidentiality
   C. Integrity
   D. Deterrence

4. What is a threat?
   A. A safeguard that reduces risk
   B. Anything that can cause harm to an asset, system, user, or organization
   C. A confirmed security incident only
   D. A patch installed on a server

5. What is a vulnerability?
   A. A weakness that can be exploited by a threat
   B. A backup copy of important data
   C. A security policy approved by management
   D. A successful recovery test

6. Which example best represents risk?
   A. A firewall rule
   B. The possibility that phishing exploits lack of MFA and causes account takeover
   C. A security awareness poster
   D. A locked server-room door

7. Which item is a security control category by nature?
   A. Directive
   B. Detective
   C. Technical
   D. Corrective

8. Which item is a security control function?
   A. Operational
   B. Managerial
   C. Physical
   D. Directive

9. Which control category is implemented through hardware, software, or automated technology?
   A. Technical
   B. Managerial
   C. Physical
   D. Operational

10. Which control category is mainly based on day-to-day people-driven procedures?
    A. Technical
    B. Operational
    C. Physical
    D. Cryptographic

11. Which control function identifies events that may have occurred?
    A. Preventive
    B. Detective
    C. Compensating
    D. Directive

12. Which is the best example of a directive control?
    A. SIEM alert
    B. Firewall rule
    C. Acceptable use policy
    D. Disk encryption

13. What is defense in depth?
    A. Using only one strong security product
    B. Using multiple layers of controls so one failure does not expose the whole environment
    C. Removing all monitoring tools
    D. Allowing administrators to bypass security controls

14. What is attack surface?
    A. Only systems already infected with malware
    B. The total set of points where an attacker could enter, interact with, or exploit an environment
    C. Only the firewall rule list
    D. Only physical doors and windows

15. Which is the best example of reducing attack surface?
    A. Exposing SSH to the whole internet
    B. Disabling unused services and closing unnecessary ports
    C. Giving all users administrator access
    D. Removing log collection

16. What is malware?
    A. Software designed to protect passwords
    B. Malicious software designed to harm systems, steal data, disrupt operations, or support unauthorized access
    C. A normal operating system update
    D. A written security policy

17. Which malware type encrypts or denies access to data and usually demands payment?
    A. Ransomware
    B. Spyware
    C. Keylogger
    D. Cryptominer

18. Which malware type disguises itself as legitimate or useful software?
    A. Worm
    B. Trojan
    C. Rootkit
    D. Wiper

19. Which malware type can self-replicate across networks without direct user action?
    A. Worm
    B. Logic bomb
    C. Trojan
    D. Spyware

20. What is social engineering?
    A. Manipulation intended to make a person reveal information or perform an unsafe action
    B. Encrypting a hard drive
    C. Installing a Linux package
    D. Running a vulnerability scan

21. What best describes phishing?
    A. A deceptive message that tries to trick users into clicking, opening, paying, or sharing credentials
    B. A firewall configuration standard
    C. A backup validation process
    D. A Linux permission mode

22. What best distinguishes spear phishing from general phishing?
    A. Spear phishing is always sent by SMS
    B. Spear phishing is tailored to a selected person, role, or organization

    A. Improve patch management
    B. Divert payments, change payroll details, or request sensitive business data

    B. Editing pictures
    C. Creating user passwords only

    A. Viewing the file contents
