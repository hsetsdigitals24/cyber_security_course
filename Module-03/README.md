## Your route through this module

**Before class:** M02: explain the local route, a listener and a successful HTTP request. If you need a refresher, tell the instructor before the practical.

Use the instructor-completed [lab sheet](../H-SETS-Class-Lab-Sheet.md) to identify your machines, accounts, versions, inputs and recovery route. Bring a folder for your own evidence; do not copy demonstration results as your work.

| Stage | Open / do | Check before moving on |
|---|---|---|
| First lesson: L05 | [Read the notes](01-Student-Notes.md), discuss the worked example, then use the matching [lab section](02-Guided-Lab.md) | Compare an explicit DNS answer with the system lookup and retrieve the service by name. |
| First assignment | Complete only L05 in the [workbook](03-Student-Workbook.md) | Include the named evidence and explain one result |
| Second lesson: L06 | Continue the notes and matching lab after the first checkpoint | Explain five selected packet references and show a fresh service retest after a controlled fault. |
| Second assignment | Complete L06 in the workbook | Correct feedback and record an independent variation |
| Portfolio milestone | P01: named service, annotated capture and DNS diagnosis | Link existing evidence; do not duplicate the same activity as extra hours |

**Completion checklist:** explain both checkpoints, submit both lesson assignments, preserve required allowed/denied or comparative tests, and record recovery plus unresolved issues. Completing this module does not automatically pass its project or gate.

Plan six class hours and six independent hours in the default teaching week. The independent hours include assignment and project work. Use the [weekly planner](../H-SETS-Weekly-Study-Plan.md) for deadlines and the [assessment guide](../H-SETS-Student-Assessment-Guide.md) for marks.
