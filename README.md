# H-SETS · Practical Cybersecurity

**18 teaching weeks · 18 modules · 40 detailed lessons**

Learn the foundations, practise in the assigned training environment and build evidence of what you can do. Each module follows the same route: **Start → Read → Practise → Review**.

## Start here

1. Read the [student guide](H-SETS-40-Lesson-Course/STUDENT-GUIDE.md) to understand the course and submissions.
2. Open [Module 01: Security Foundations and the Profession](H-SETS-40-Lesson-Course/modules/Module-01/README.md).
3. Continue through the modules below in week order.

Returning students: open your current module and choose **Student notes** or **Practice and assessment**.

## Minimum system requirements

| Component | Minimum |
|---|---|
| Processor | Intel Core i5, 8th generation or newer |
| Storage | 500 GB drive capacity |
| Memory | 16 GB RAM |
| Hardware virtualisation | Enabled in BIOS/UEFI before VM activities |

An SSD is recommended. Plan approximately 200 GB free for lab images and snapshots, then check the actual requirements for the assigned lab. Run staged guests; this minimum does not mean the full multi-server range can run simultaneously on one laptop. An instructor must arrange additional capacity or hosted services where required and verify compatibility with the selected images. Lab execution and beginner timing still require pilots.

The timetable covers teaching. Longer portfolio projects may require completion time after Week 18. Lab execution and beginner timing still require instructor pilots. See the [source and adaptation record](H-SETS-40-Lesson-Course/SOURCE-AND-ADAPTATION.md) for provenance.
