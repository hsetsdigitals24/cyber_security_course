# M18 student workbook

Use the [student assessment guide](../H-SETS-Student-Assessment-Guide.md) for course weights and pass rules. Named lesson assignments contribute to knowledge/scenario and practical categories; “formative” describes the improvement feedback, not an exemption from grading. Raw marks below are unchanged.

Before submitting, check the exact lesson ID, all requested items, actual test results and evidence references. Use the instructor's private destination and deadline on your [lab sheet](../H-SETS-Class-Lab-Sheet.md). Return to the [module route](README.md) after feedback.
Each lesson assignment is 30 marks and about 60 minutes after guided work: MCQs 5, scenarios 10, practical 15. No answers are included.

## L35 end-of-lesson assignment
### Knowledge check
1. After recovery, the server answers ping and its service is running. Which additional result best establishes the required business service?
   A. An administrator can open the service configuration
   B. The intended standard user completes the required transaction with correct content and access
   C. The server has the same IP address as before the disruption
   D. The backup job recorded a successful copy
2. You must explain why an endpoint event is absent from a dashboard. Which diagram best supports the investigation?
   A. A diagram of physical machines without collection links
   B. A product inventory grouped by vendor
   C. A network map containing addresses but no event-processing stages
   D. A source-to-collector-to-processing-to-storage/view diagram with dependencies and boundaries
3. A dashboard shows zero alerts for one agent in a selected hour. Which conclusion is supported without further checks?
   A. The agent collected every event but none was suspicious
   B. The host generated no security-relevant activity
   C. No alerts are shown in that view and interval; collection and filter coverage still need checking
   D. All enabled rules were tested and produced no matches
4. A required denied-access test was not run because the second account was unavailable. How should it be reported?
   A. Not run, leaving the requirement unverified, with the missing prerequisite and next action recorded
   B. Passed because the permission settings match the design
   C. Passed with a limitation because the authorised user's test succeeded
   D. Not applicable because there was no account available on test day
5. A reviewer asks which evidence supports your claim that access is restricted. Which response is strongest?
   A. Link the final permission screenshot without identifying tested accounts
   B. Link the requirement, implemented control, named allowed/denied tests and their actual evidence
   C. Link the installation history and list all tools used
   D. Link the test plan with expected results but no actual observations

### Scenarios — 5 marks each
1. An agent is active, FIM works, but application events stopped after an update. Propose ordered checks and distinguish a current repair from recovery of the missing history.
2. A source account and a file change occur close together. Explain what additional evidence would support a causal link and what remains unknown.

### Practical — 15 marks
Complete a requirement-to-evidence matrix and the rehearsal's two-hypothesis investigation. Demonstrate one fresh monitoring or recovery test in the allocated lab. Submit L35.md, diagram, actual evidence, and P01–P07 gap register. Link this to P08 preparation; do not mark G4 passed.

## L36 end-of-lesson assignment
### Knowledge check
1. You tested two department-role boundaries in a fictional Windows lab. Which portfolio statement best fits that evidence?
   A. Secured enterprise-wide access for all departments
   B. Prevented unauthorised access across the organisation
   C. In a simulated IAM lab, tested the two specified role boundaries; actual results and limitations are linked
   D. Validated every Windows permission because the two selected tests passed
2. Collection is working again but records from the outage have not been reconciled. Which handover is most useful?
   A. Current state, fresh recovery evidence, unresolved interval, next owner and next check
   B. A recovery timestamp and “resolved” because the latest event arrived
   C. The configuration backup without describing the remaining gap
   D. A screenshot of active status and a list of installed agents
3. On the default route, a learner attended M18 but has not completed P08 and final G4. Which status is accurate?
   A. Complete because attendance establishes the practical requirement
   B. Complete if the current overall average exceeds 70%
   C. Complete because the rehearsal covers similar skills
   D. Integrated checkpoint reached; capstone and final requirements remain pending
4. A real secret was committed, then its filename was added to .gitignore. Which statement is correct?
   A. The next commit automatically removes all historical copies
   B. The ignore entry does not remove committed history; the exposure needs the authorised credential-response process
   C. The remote copy becomes unreadable once the local file is ignored
   D. Only collaborators who cloned before the ignore entry can read the historical secret
5. After an application update, FIM events arrive but application audit events do not. What is the best initial approach?
   A. Reinstall the entire platform before inspecting the endpoint
   B. Lower detection thresholds because FIM proves every source is collected
   C. Form a source/path hypothesis and inspect a fresh local application event before following the collection chain
   D. Close the issue because the active agent rules out collection problems

### Scenarios — 5 marks each
1. A portfolio claims “99% detection accuracy” from six authored test cases. Rewrite it and explain what was actually measured.
2. A restored file matches the backup hash but the required user is denied. Explain the next step and how to report readiness.

### Practical — 15 marks
Submit a private index for exactly P01–P08, two evidence-backed CV statements, a three-minute project explanation and a professional handover. Identify one competence gap and a measurable practice plan. Do not publish automatically. Record assisted work and individual contribution.
