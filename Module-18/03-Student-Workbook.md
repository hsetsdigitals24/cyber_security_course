# M18 student workbook
Each lesson assignment is 30 marks and about 60 minutes after guided work: MCQs 5, scenarios 10, practical 15. No answers are included.

## L35 end-of-lesson assignment
### Knowledge check
1. Which best proves a business service?
   A. Ping alone
   B. Required transaction with correct content/access
   C. VM power state
   D. Product logo
2. An architecture diagram should show:
   A. Only vendors
   B. Only colours
   C. Only computer names
   D. Dependencies, boundaries and actual flows
3. Quiet alerts establish:
   A. No compromise
   B. Complete collection
   C. Only absence of alerts in the observed view
   D. Correct rules
4. An unperformed critical test should be:
   A. Marked unverified
   B. Assumed passed
   C. Deleted
   D. Replaced by a settings screenshot
5. Which links a conclusion to evidence?
   A. Confidence alone
   B. Requirement-control-test-evidence traceability
   C. Tool count
   D. Word count

### Scenarios — 5 marks each
1. An agent is active, FIM works, but application events stopped after an update. Propose ordered checks and distinguish a current repair from recovery of the missing history.
2. A source account and a file change occur close together. Explain what additional evidence would support a causal link and what remains unknown.

### Practical — 15 marks
Complete a requirement-to-evidence matrix and the rehearsal's two-hypothesis investigation. Demonstrate one fresh monitoring or recovery test in the allocated lab. Submit L35.md, diagram, actual evidence, and P01–P07 gap register. Link this to P08 preparation; do not mark G4 passed.

## L36 end-of-lesson assignment
### Knowledge check
1. Honest portfolio wording is:
   A. “Protected a real bank” for a classroom lab
   B. “Guaranteed expert”
   C. “Simulated IAM project; my access tests are linked”
   D. “Zero risk achieved”
2. A handover needs:
   A. Owner, state, evidence and next action
   B. Only a title
   C. All credentials
   D. Only tool names
3. M18 attendance on the default route means:
   A. Automatic graduation
   B. All projects passed
   C. G4 permanently passed
   D. Integrated checkpoint; final requirements may remain
4. A .gitignore entry:
   A. Rotates leaked keys
   B. Does not remove secrets already committed
   C. Guarantees privacy
   D. Deletes remote history
5. Best response to an unfamiliar fault:
   A. Make many changes
   B. Guess confidently
   C. State a hypothesis and a discriminating check
   D. Hide the error

### Scenarios — 5 marks each
1. A portfolio claims “99% detection accuracy” from six authored test cases. Rewrite it and explain what was actually measured.
2. A restored file matches the backup hash but the required user is denied. Explain the next step and how to report readiness.

### Practical — 15 marks
Submit a private index for exactly P01–P08, two evidence-backed CV statements, a three-minute project explanation and a professional handover. Identify one competence gap and a measurable practice plan. Do not publish automatically. Record assisted work and individual contribution.
