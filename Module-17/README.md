## Your route through this module

**Before class:** M05/M12/M16: file hashes, access boundaries, HTTP operations and evidence preservation. If you need a refresher, tell the instructor before the practical.

Use the instructor-completed [lab sheet](../H-SETS-Class-Lab-Sheet.md) to identify your machines, accounts, versions, inputs and recovery route. Bring a folder for your own evidence; do not copy demonstration results as your work.

| Stage | Open / do | Check before moving on |
|---|---|---|
| First lesson: L33 | [Read the notes](01-Student-Notes.md), then complete lab sections A–C: permissions, independent backup and timed recovery | Show allowed/denied operations, protected backup, restored content/access and measured recovery time. |
| First assignment | Complete only L33 in the [workbook](03-Student-Workbook.md) | Include the named evidence and explain one result |
| Second lesson: L34 | Continue the notes, then complete lab section D: risk and responsibility | Explain five contextual risks, their owners/treatments, the responsibility boundary and the management decision needed. |
| Second assignment | Complete L34 in the workbook | Correct feedback and record an independent variation |
| Portfolio milestone | P07: access boundary, independent backup and recovery record | Link existing evidence; do not duplicate the same activity as extra hours |

**Completion checklist:** explain both checkpoints, submit both lesson assignments, preserve required allowed/denied or comparative tests, and record recovery plus unresolved issues. Completing this module does not automatically pass its project or gate.

Plan six class hours and six independent hours in the default teaching week. The independent hours include assignment and project work. Use the [weekly planner](../H-SETS-Weekly-Study-Plan.md) for deadlines and the [assessment guide](../H-SETS-Student-Assessment-Guide.md) for marks.
