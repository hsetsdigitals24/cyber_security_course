# M17 student workbook
Each lesson: 30 marks, approximately 60 minutes after guided setup. Five MCQs (5 marks), two scenarios (5 each), independent practical (15). Keep expected and actual results separate.

## L33 end-of-lesson assignment
### Knowledge check
1. Moving to SaaS removes which duty automatically?
   A. Choosing access
   B. All backup decisions
   C. None of these
   D. Managing users

2. RPO describes?
   A. Acceptable data-loss interval
   B. Time to boot
   C. Number of copies
   D. Key strength

3. Read-only should fail which test?
   A. Authorised read
   B. Overwrite
   C. Authentication
   D. Permitted viewing

4. A same-disk copy protects against?
   A. Site loss
   B. All ransomware
   C. Provider failure
   D. Some accidental file loss

5. Recovery timing ends when?
   A. Copy starts
   B. Required service checks finish
   C. User logs in
   D. Backup begins

### Scenarios
1. A manager says cloud providers handle all permissions and backups. Explain the responsibility boundary using a service model.
2. The backup is 30 hours old and verified restore takes 8 minutes. Assess the 24-hour RPO and 15-minute RTO.

### Independent practical
Prove anonymous denial, reader access/write denial, writer access, deletion and recovery. Record backup age, measured full recovery time and independent backup location.

Submit L33.md, evidence IDs and expected/actual tests with timestamps and limitations. Milestone: P07 access/recovery.

## L34 end-of-lesson assignment
### Knowledge check
1. Who accepts residual risk?
   A. Scanner
   B. Authorised risk owner
   C. Hash
   D. Student automatically

2. A policy states?
   A. Mouse clicks only
   B. Packet count
   C. Management requirements
   D. Checksum

3. Control evidence should show?
   A. Only a document
   B. Only installation
   C. A chart
   D. Relevant actual operation

4. Risk connects?
   A. Asset, condition, event and consequence
   B. Tool name only
   C. Score only
   D. Price only

5. An untested control is?
   A. Effective
   B. Proposed or unverified
   C. Compliant
   D. Closed risk

### Scenarios
1. Anonymous reads fail, but writers can erase all backups. Write a risk and treatment with owner.
2. A report claims complete compliance after six access tests. Rewrite it accurately.

### Independent practical
Create five contextual risks with owners, evidence, treatments and residual risk, plus responsibility matrix and 150-word management decision request.

Submit L34.md, evidence IDs and expected/actual tests with timestamps and limitations. Milestone: P07 risk and handover.
